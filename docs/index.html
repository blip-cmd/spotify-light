A Luxury Aesthetic for Your Spotify Client

Say goodbye to Spotify's standard dark screen. Upgrade to a highly customized, glassmorphic light-mode experience optimized for visual excellence, micro-animations, and smooth component flow.

How It Works

Spotify-Light hooks directly into Spotify's client engine via Spicetify. It overrides standard interface variables and injects custom styles dynamically.

Spicetify is a CLI customization tool that unlocks styling on Spotify's desktop client. It creates a backup of the original assets and enables full stylesheet injection. Because Microsoft Store apps are heavily protected, we migrate your app to the official Spotify standalone client first.

Using Spicetify's mapping variables, color.ini establishes HSL color tokens. This forces Spotify's internal styling to replace dark values with a crisp, soft off-white canvas, warm sidebar tones, and gorgeous purple play buttons.

To avoid dark leftovers, user.css overrides nested sub-components. Context dropdowns are turned into rounded white floating cards, lyrics pages are styled with a soothing lavender gradient, and scrollbars and sliders are customized to blend smoothly.

How To Use It

Follow these quick powershell commands to easily set up the theme on your Windows PC.

1

Uninstall UWP Client

Spicetify cannot patch Microsoft Store packages. Run this in PowerShell to clean it up:

Get-AppxPackage *SpotifyMusic* | Remove-AppxPackage
2

Install Desktop Client

Download and run the official standalone desktop client silently in your terminal:

Invoke-WebRequest -Uri "https://download.spotify.com/SpotifyFullSetup.exe" -OutFile "SpotifyFullSetup.exe"; .\SpotifyFullSetup.exe /silent
3

Install Spicetify

Run the official installation script to set up Spicetify-cli on your system:

iwr -useb https://raw.githubusercontent.com/spicetify/cli/main/install.ps1 | iex
4

Clone & Apply Theme

Clone the theme directly into Spicetify's active directory, configure, and apply:

cd "$env:APPDATA\spicetify\Themes"; git clone https://github.com/blip-cmd/spotify-light Spotify-Light; spicetify config current_theme Spotify-Light color_scheme light; spicetify apply
